사용하는 Google 데이터

  • drive.file: 앱이 만든 파일을 Google Drive에 만들고 고칩니다.
  • drive.readonly: 사용자가 지정한 HQ 폴더 안의 파일을 읽기만 합니다. 그 밖의 폴더는 읽지 않으며, 이 권한으로 파일을 고치거나 지우지 않습니다.

데이터 사용과 보관

  • 가져온 데이터는 운영자 본인의 업무 문서를 확인하고 고치는 데만 씁니다.
  • 읽은 파일은 운영자의 컴퓨터에 임시로 저장되고, 작업이 끝나면 지웁니다.
  • Google 사용자 데이터를 판매하지 않으며, 광고에 쓰지 않습니다. 위 목적 외로 제3자에게 전송하지 않습니다.
  • 이 앱의 Google 사용자 데이터 사용은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

접근 철회

Google 계정 권한 페이지에서 언제든 이 앱의 접근을 철회할 수 있습니다.
