# Issue #38 공통 실행 도구 개발 인계

- `agy-run.mjs`는 지침과 입력 파일 또는 질문을 받아 Antigravity를 비대화형으로 실행한다. 기존 Loki·Fury 실행기는 공통 도구를 사용하고 기존 표기와 Gemini CLI 폴백을 유지한다.
- 검토는 도구 없는 프로필로 실행한다. 조사는 공개 웹 검색·읽기 프로필로 실행해 URL과 기준일이 있는 근거만 반환한다.
- 설치된 Mac mini의 agy 1.5.18에서 Node 파이프로 `-p`와 `stream-json`이 종료하는 것을 확인했다. PTY 없이 stdin을 닫고 제한 시간을 적용한다.
- Loki와 Fury를 각각 한 번, 공개 예약 소프트웨어 가격 조사를 한 번 실제 실행했다. 출력 원문은 PR 본문에 있다.
- Tony 검토와 QA 다음에 HJ가 병합한다. Thanos 연결(#44)은 이 도구의 조사 모드를 사용한다.
